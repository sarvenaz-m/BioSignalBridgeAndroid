# Provenance and confidentiality

BioSignal Bridge is an independent public implementation. Confidentiality and NDA boundaries are respected throughout its source, data, interface and documentation.

## Public inputs

The project contains original Kotlin, JavaScript and Python application code, public Android and Bluetooth concepts, an original sample packet contract, and a documented MIT-BIH ECG excerpt. The bundled Manrope font retains its SIL Open Font License. Open-source dependencies are declared in the Gradle catalog and JavaScript lockfile.

## Confidential material stays outside

Employer code, internal architectures, private endpoints, credentials, customer recordings, confidential circuit designs, proprietary device protocols and employer visual assets are excluded. No former employer's source code or technical documents were used as implementation material.

The example service UUIDs, characteristic, packet structure and interface were created for this project. They are not extracted from a commercial product. Professional experience can inform the engineering problem without reproducing a private system or implying employer sponsorship.

## A traceable recording

The public preview retains its URL, record number, lead, original and prepared rates, scale, preparation method and checksums. Native preview exports include that record in `provenance.json`; the browser embeds it with its data.

`DATA.md` explains preparation and `NOTICE.md` lists licences. No personal or customer recordings are bundled. This note describes the repository's materials; it does not publish or interpret a private agreement.
